📊 Personal Expense Tracker
A lightweight, web-based financial management application built with Python (Flask) and SQLAlchemy. This tool allows users to log daily expenses, categorize spending, and visualize their financial habits.

🚀 Features
User Dashboard: Overview of total spending and recent transactions.

CRUD Operations: Create, Read, Update, and Delete expenses easily.

Categorization: Group expenses (e.g., Food, Transport, Rent, Entertainment).

Responsive Design: Fully mobile-responsive UI built with Bootstrap 5.

Data Persistence: Uses SQLite for a portable, serverless database experience.

🛠️ Tech Stack
Backend: Flask (Python)

Database: SQLAlchemy (ORM) & SQLite

Frontend: HTML5, CSS3, Bootstrap 5

Templating: Jinja2
